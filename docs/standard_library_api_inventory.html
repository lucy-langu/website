Lucy 2.0.7 Standard Library API Inventory

This page is the source-derived signature inventory for the shipped stdlib/*.lucy files. It complements STANDARD_LIBRARY.md: the main reference explains behavior and usage, while this page makes it easy to verify that a shipped class or function has not been omitted from the documentation set.

The inventory is source-oriented and should be regenerated whenever a standard-library source file changes. For the core filesystem facade, signatures, accepted input descriptions, return contracts, error conditions, platform targets, and examples are additionally tracked in contracts/core_api.json.

Lucy 2.0.7 additive helper API — module 1.1.0
