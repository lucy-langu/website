# Documentation source snapshot

This folder contains the Markdown documentation, ADRs, and `.lucy` examples copied from the Lucy 2.0.7 source archive used to generate the static HTML documentation pages in `docs/`.


- Published learner pages are the HTML files in `docs/` and `docs/stdlib/`.
- `_source/` is a maintainer reference snapshot and is not part of navigation.
- Specs and verification records retain their original wording and scope; specifications are not implemented-feature claims.
- Update the HTML pages and this source snapshot when Lucy's implementation documentation changes.
