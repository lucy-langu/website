PAW & ECOSYSTEM

More than an interpreter.

The ecosystem is designed around a Lucy-native workflow. Paw is the first-party CLI; packages and extensions cover reusable code and native integration.

Paw

Project scaffolding, build/test frontends, package operations, extension templates, stdlib manifest, and documentation workflows from one CLI.

Paw

Pure-Lucy packages

Project-local packages are source-based and importable. The shipped package manager currently supports local sources and lockfile bookkeeping.

Local source workflow

Native extensions

Shared C++ modules can expose functions, constants, modules, and resource-backed objects through the public extension boundary.

C++ integration
Honest roadmap: remote registry publishing/downloading, dependency solving, production LSP, formatter, linter, and DAP are not shipped in this snapshot. Specifications are not implementation.
ARCHITECTURE

Native implementation. Language-level workflows.

EVOLUTION

What changed through .

Version focuses on stability, tooling consolidation, ecosystem contracts, and diagnostics rather than introducing a new syntax wave.

2.0.0

Language/runtime consolidation: brace syntax, runtime type contracts, structs, lambdas, ranges, modules, standard-library organization, extension boundary and REPL tooling.

2.0.1

Reliability and documentation: UTF-8 string behavior, conversion and CSV/JSON fixes, REPL improvements, test coverage, and runnable integration examples.

2.0.2

REPL introspection and completion, built-in type extensions, module-path inspection, and stricter conversion behavior.

2.0.3

Core filesystem objects Dir, File, and Path; typo suggestions; module metadata and API contract tooling.

2.0.4

Runtime hardening: safe iteration snapshots, bounded recursive operations, checked numeric behavior, date handling, and validation improvements.

2.0.5

Windows/MSVC build fixes, stack-safety hardening, Unicode string iteration, range indexing corrections, and expression interpolation.

2.0.6

String semantics and documentation consistency: Unicode code-point indexing/iteration and full-expression interpolation with $Ellipsis.

2.0.7

Paw consolidation, local package workflow hardening, project command metadata and binstubs, diagnostics/release process, and formal registry/resolver/LSP specifications. No intentional syntax or runtime semantic expansion.

See the changelog in the source repository for granular fixes and verification details.
