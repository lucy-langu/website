# Lucy Website

Static website for Lucy 2.0 series, designed for GitHub Pages.

The `/docs` directory contains generated multi-page learning and reference docs based on the Lucy 2.0.7 source archive. Start at `docs/index.html`. Includes beginner guides, language reference, module API pages, Paw/ecosystem docs, examples, changelog and maintainer verification notes.

Publish from repository root (`main` branch, `/ (root)`) using GitHub Pages. No build step is required. Bootstrap and syntax highlighting use CDNs. Update release metadata in `version.js`; stable pages describe the 2.0 series and release-specific changes are kept in history/changelog.
