BUILD FROM SOURCE

Build the 2.0 series

Requirements: a C++17-capable compiler, CMake, and platform build tools. SQLite is an optional feature.

Linux / macOS / Unix-like

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
./build/lucy --version
./build/paw --help

Optional SQLite

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DLUCY_ENABLE_SQLITE=ON
cmake --build build --parallel

SQLite integration is optional and must be enabled at build time.

Install to a user prefix

cmake --install build --prefix "$HOME/.local"
export PATH="$HOME/.local/bin:$PATH"

Exact paths may vary by generator, platform, and install configuration. Consult the repository's environment/install guide.

VERIFY

Verify your build

Version

lucy --version

Tests

ctest --test-dir build --output-on-failure

Paw

paw --help
paw test ./build/lucy

Release verification status

2.0.7 release documentation records Linux verification. Windows and macOS are not considered verified until their own build/test results are recorded. Do not treat source build instructions as proof of cross-platform status.
